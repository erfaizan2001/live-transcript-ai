# Live Transcript App

A real-time speech-to-text transcription web app built using Next.js and Tailwind CSS.

## Features
- Live microphone transcription
- Real-time transcript updates
- Start / Stop listening
- Copy transcript
- Clear transcript
- Responsive modern UI

## Tech Stack
- Next.js
- Tailwind CSS
- Deepgram API

## Run Locally

```bash
npm install
npm run dev
